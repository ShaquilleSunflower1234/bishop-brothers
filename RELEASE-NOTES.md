# Bishop Brothers 1.0.0

Add Ex-Con Andre Bishop and Raymond Bishop to an existing Fight Night Champion boxer save from one Windows app.

Plug in Xbox 360 USB storage, select the detected save, and click **Add Bishops**. The app backs up the original, preserves existing boxer records, adds the missing Bishops, rebuilds hashes, signs and verifies the package, and returns it to the correct numbered folder automatically. Copied Content folders can be dropped into the window. Horizon and separate signing files are not needed.

The download is free. Optional donations do not affect app features.

The project owner reported Xbox success on October 14, 2026. Local tests covered preservation, duplicate prevention, package hashes, signing, folder discovery, ownership, automatic return, invalid signatures, and changed-source protection. The built-in signer reproduces a previously Xbox-tested Horizon-signed save byte for byte when re-signing it.

Requires an existing supported boxer save. Career/story saves, unknown layouts, full verified slot ranges, and FATX image storage are not supported. Cloud upload remains an Xbox 360 dashboard step. Keep the automatic backup until your in-game checks pass.

Download **BishopBrothers-1.0.0-Windows.zip**, extract it, and open BishopBrothers.exe. This executable is not Authenticode-signed. SHA256SUMS.txt records the release archive hashes.
